# CaseWave Documentation

CaseWave documentation explains every package, type, function, theme field, theme registry utility, and practical usage pattern required to use the CaseWave ecosystem confidently.

This documentation is written for:

- Developers installing CaseWave for the first time
- React developers building graph-based interfaces
- Package users integrating ready-made themes
- Library authors extending CaseWave
- Teams building investigation boards, evidence systems, workflow editors, OSINT boards, and visual analysis tools
