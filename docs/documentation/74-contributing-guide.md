```txt
fork
branch
develop
test
pull request
review
```

Prefer conventional commits.

```txt
feat:
```

Should include:

```txt
summary
motivation
screenshots if relevant
tests
```

# Review Standards

Review for:

```txt
architecture fit
performance
API stability
docs completeness
```
