# 85. FAQ Knowledge Base

FAQ should be curated knowledge.

Not dumping ground.

---

# Contents

```txt
FAQ Structure

```

---

# FAQ Categories

Examples:

```txt
getting started
api questions
themes
plugins
performance
licensing
```

---

# Good FAQ Question

Example:

```txt
How do I persist large graphs safely?
```

Specific.

Searchable.

Useful.

---

# FAQ Article Format

Each entry:

```txt
question
short answer
deep answer
related links
```

---

# Link FAQ To Docs

Each FAQ points into:

```txt
guides
api docs
cookbook
troubleshooting
```

---

# Knowledge Base Articles

Longer than FAQ entries.

Examples:

```txt
architecture explainers
decision rationale
best practices
```

---

# Search First Design

Design for lookup.

Critical.

---

# FAQ Maintenance

Review stale entries.

Prune duplicates.

---

# Anti Patterns

Avoid:

```txt
FAQ as substitute for missing docs
duplicate contradictory answers
```

---

# FAQ Examples To Include

Questions like:

```txt
Why hybrid renderer?
How do plugins isolate failures?
How do themes compose?
```

---

# FAQ vs Troubleshooting

FAQ = common questions.

Troubleshooting = incident fixing.

Different.
