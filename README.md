# CaseWavejs

Production-grade TypeScript toolkit for investigation boards, collaborative graph workflows, and interactive cases.

## Install

```bash
npm install @casewavejs/core
```

## Packages

### Core Engine

- https://www.npmjs.com/package/@casewavejs/core

```bash
npm i @casewavejs/core
```

### React Integration

- [https://www.npmjs.com/package/@casewavejs/react](https://www.npmjs.com/package/@casewavejs/react)

```bash
npm i @casewavejs/react
```

### Layout System
