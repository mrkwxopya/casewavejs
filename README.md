# CaseWavejs

Production-grade TypeScript toolkit for investigation boards, collaborative graph workflows, and interactive cases.

## Install

```bash
npm install @casewavejs/core
```

## Packages

- @casewavejs/core
- @casewavejs/react
- @casewavejs/layout
- @casewavejs/plugins
- @casewavejs/themes
