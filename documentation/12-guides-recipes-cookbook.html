Quick Recipes ​

Minimal Investigation Board ​

tsx
import {
 CaseWaveGraph
}
from "@casewavejs/core"

import {
 CaseWaveCanvas
}
from "@casewavejs/react"

const graph=
new CaseWaveGraph()

graph.addNode({
 id:"suspect_1",
 type:"person",
 data:{
  label:"Suspect"
 }
})

export default function App(){

 return(
   <CaseWaveCanvas
      graph={graph}
   />
 )
}

What this demonstrates:

  • graph creation

  • node rendering

  • minimal setup

Anti Patterns ​

Avoid:

Mutating raw node objects.

Bad.

Random IDs.

Bad.

Use deterministic ids.

Putting huge payloads in node data.

Bad.

Use references.

Thousands of ungrouped nodes.

Bad.

Use clusters.
