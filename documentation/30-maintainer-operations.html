Release Engineering ​

Release flow:

txt

validate
tag
publish
verify
announce

Pre-Release Checklist ​

Must verify:

txt

typecheck green
examples build
docs current

Release Branching ​

Use:

txt

Stabilize there.

Versioning Rules ​

Use semantic versioning strictly.

txt
major = breaking
minor = features
patch = fixes

Never abuse patch.

For risky releases:

txt

rc2
rc3

Stabilize before final.

txt

changed

npm view package version

Verify:

txt

txt
deprecate
rollback

communicate
